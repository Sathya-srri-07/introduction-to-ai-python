# AI Study Assistant

## 📌 Project Overview

AI Study Assistant is a simple AI-powered Python application that helps students understand study topics easily.

The application uses the Google Gemini API to generate:
- Simple explanations
- 5 important key points
- 3 practice questions

## 🚀 Features

- Accepts any study topic from the user
- Generates simple explanations using AI
- Provides 5 important key points
- Creates 3 practice questions
- Simple command-line interface
- Uses Google Gemini API
- Secure API key handling using environment variables

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Google GenAI Python SDK
- Visual Studio Code
