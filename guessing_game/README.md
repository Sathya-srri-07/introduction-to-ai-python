# Number Guessing Game

## Module 2 – Python Mini Project

### Project Objective

The Number Guessing Game is a simple Python project where the computer randomly selects a number between 1 and 100. The player tries to guess the number, and the program provides hints until the correct number is guessed.

## Features

- Generates a random number
- Accepts guesses from the user
- Gives "Too high" or "Too low" hints
- Counts the number of attempts
- Displays a congratulatory message when the correct number is guessed

## Technologies Used

- Python 3

## Concepts Used

- Variables
- User input
- `if-elif-else`
- `while` loop
- `random` module
- Basic problem-solving
