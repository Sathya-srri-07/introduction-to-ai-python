# Student Performance Predictor

## Project Overview

Student Performance Predictor is a simple Machine Learning project that predicts a student's final marks based on study hours, attendance, previous marks, and completed assignments.

## Features

- Predicts final student marks
- Uses Machine Learning
- Provides study recommendations
- Displays a Study Hours vs Final Marks graph
- Evaluates the model using MAE and R² Score

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Model

Linear Regression is used to predict the student's final marks.

### Input Features

- Study Hours
- Attendance
- Previous Marks
- Assignments Completed

### Output

- Predicted Final Marks
- Study Recommendation
