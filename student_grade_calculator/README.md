# Student Grade Calculator

## Module 2 – Python Mini Project

### Project Objective

The Student Grade Calculator is a beginner-friendly Python project that calculates a student's total marks, average marks, and grade based on marks entered for five subjects.

## Features

- Accepts the student's name
- Accepts marks for five subjects
- Calculates total marks
- Calculates average marks
- Assigns a grade based on the average
- Displays the final result

## Technologies Used

- Python 3

## Concepts Used

- Variables
- User input
- Data types
- Arithmetic operators
- If-elif-else statements
- Basic calculations

## Grading System

| Average | Grade |
|--------:|:-----:|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |
